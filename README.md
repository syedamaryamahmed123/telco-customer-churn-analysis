# Telco Customer Churn Analysis

## 📌 Project Overview

An end-to-end customer churn analytics project analyzing
customer demographics, services, account information,
tenure, monthly charges, total charges, and churn behavior.

The project combines Python, SQL, MySQL, Power BI, and
machine learning techniques to transform raw customer data
into actionable business insights.

## 🎯 Business Objectives

- Understand overall customer churn
- Identify customer segments with higher churn
- Analyze churn across services and contracts
- Examine the relationship between tenure and churn
- Analyze monthly and total charges
- Identify customer characteristics associated with churn
- Build an interactive dashboard for decision-making

## 🧹 Data Cleaning

The dataset was cleaned and validated using Python/Pandas.

Key steps included:

- Handling missing values
- Checking duplicate records
- Validating customer IDs
- Converting numerical fields to appropriate data types
- Creating analytical groups
- Preparing the cleaned dataset for SQL and Power BI
